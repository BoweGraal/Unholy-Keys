# Practice songs

Put copyright-free songs in this folder. Anyone who opens dance practice sees them in the song drop-down under **Unholy Keys songs**. You don't need to edit any code or list.

- **Formats:** .mp3 (best, smallest), .ogg, .m4a, .wav, .flac
- **Titles:** the file name becomes the title in the list. `Neon_Riot - Night Drive.mp3` shows as "Neon Riot - Night Drive".
- **Size:** keep each file under 50 MB. GitHub refuses files over 100 MB, and big files load slowly on phones. A 4-minute MP3 at 192 kbps is about 6 MB.
- **Uploading on github.com:** open this `songs` folder → **Add file → Upload files** → drop the songs in → **Commit changes**. The site updates a minute or two later.
- Only add music you have the rights to share: your own tracks, or tracks with a licence that allows it (CC0, CC-BY with credit, royalty-free).
